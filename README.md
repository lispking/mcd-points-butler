# 麦管家 mcd-points-butler

> 你的麦当劳积分与优惠券资产管家：会过期的先处理，闲置的用起来，消费的省着花。

麦管家是一个基于**麦当劳中国官方 MCP Server**（`https://mcp.mcd.cn`）开发的 WorkBuddy 专家（Expert）。它不替你花钱，只帮你管资产——把散落在麦当劳 App 各处的**积分、优惠券、商城订单**当作一个整体来打理，让每一分资产都有去向。

<img src="expert/mcd-points-butler/avatars/expert.png" alt="avatar" width="160" />

## 它解决什么问题？

- **积分悄悄过期**：账户里的积分有有效期，过期即归零，但很少有人盯着。麦管家每次对话都会检查「即将过期积分」，并给出最优兑换建议。
- **优惠券领了就忘**：麦麦省的券一键可领，但领完不用等于没领。麦管家区分「可领 / 已领未用 / 临期」三种状态，临期券会提醒你下次点餐优先用。
- **商城兑换拍脑袋**：积分商城商品那么多，换哪个最划算？麦管家用「价值密度 = 商品价值 ÷ 所需积分」排序，结合你的历史偏好给建议，下单前出确认单。
- **抽奖全凭心情**：先看奖品池和消耗规则，粗算期望价值，再决定抽不抽——不怂恿，只参谋。

## 核心功能（5 大剧本）

| 剧本 | 触发语 | 做什么 |
|---|---|---|
| 资产巡检 | 「检查我的积分和优惠券」 | 一次盘点三类资产，输出资产速览 + 行动清单 |
| 积分急救 | 「帮我把即将过期的积分换成最划算的商品」 | 临期积分 → 商城核验 → 价值密度排序 → 确认单 → 兑换 |
| 领券规划 | 「领取今天的可用优惠券并规划点餐优惠」 | 一键领券 → 复核到账 → 临期券用券节奏建议 |
| 抽奖参谋 | 「现在抽奖划算吗？」 | 读活动规则与奖品池 → 期望价值粗算 → 抽/不抽建议 |
| 资产月报 | 「给我一份麦当劳资产月报」 | 积分 + 券 + 订单汇总：复盘、到期风险、下月建议 |

## 安装

### 前置条件

1. 一台装有 [WorkBuddy](https://www.workbuddy.cn/) 的设备
2. 麦当劳中国 MCP Token：登录 [open.mcd.cn/mcp](https://open.mcd.cn/mcp) → 右上角「控制台」→ 点击「激活」申请

### 方式一：WorkBuddy 直接搜索（推荐）

专家已上架 WorkBuddy 开放平台。打开 WorkBuddy，左侧边栏【专家·技能·连接器】→【专家】，在顶部搜索框输入「麦管家」即可找到该专家，点击安装并启用，按引导连接麦当劳 MCP（专家包内置凭证表单，填入 Token 即可）。若搜索不到或安装后提示工具未挂载，改用方式二手动配置连接器。

### 方式二：手动配置 MCP

1. **WorkBuddy**：左侧边栏【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置MCP】，粘贴仓库根目录 [`mcp-config.example.json`](mcp-config.example.json) 的内容，将 `${MCD_MCP_TOKEN}` 替换为你的真实 Token，保存并启用。
2. **其他 MCP 客户端**：Cherry Studio / Cursor / Trae / VSCode 等支持 Streamable HTTP 的客户端可直接导入同一份示例配置；个别客户端要求 `type` 写作 `http`，按客户端文档微调即可。

> 示例配置只含环境变量占位符，请勿将真实 Token 提交到任何仓库。

## 使用示例

```
你：检查我的积分和优惠券
麦管家：
  资产速览（2026-10-09）
  | 资产 | 状态 |
  |---|---|
  | 积分 | 可用 1,820，其中 300 分将于 10-15 过期 ⚠️ |
  | 券 | 已领未用 3 张（1 张 10-12 临期）；可领 5 张未领 |
  行动清单：
  1. 300 临期分建议兑换「麦乐鸡 5 块券」（价值密度最高，详情已核验）
  2. 有 1 张临期板烧券，下次点餐优先用
  3. 麦麦省有 5 张券可领，要我帮你一键领取吗？
```

```
你：现在抽奖划算吗？
麦管家：当前活动消耗 100 积分/次，奖品池共 6 项（未公布概率）。
奖品池最高价值约 108 积分等值的巨无霸券，粗算期望约 35-50 积分/次，
低于 100 积分/次的成本——等于用 100 分的成本换回 35-50 分的东西。
建议：不抽，把积分留给临期兑换。要我帮你看看商城吗？
```

## 目标用户

- 有麦当劳消费习惯、账户里躺着积分和券但经常忘用的人
- 想知道「积分到底怎么花最值」的精明消费者
- 用 WorkBuddy 或其他 MCP 客户端、喜欢用对话管理日常琐事的效率玩家
